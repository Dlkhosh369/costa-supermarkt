## Regels voor het project
- Git commit-berichten zijn in het Engels (feat:, fix:, docs:, style:).
- Raak `.env` nooit aan en zet geheimen nooit in code.
- TypeScript staat in `webserver/ts/`. De map `webserver/js/` wordt door `tsc` gemaakt, pas die niet aan.
- Compileren: `cd webserver` en dan `npx tsc ts/categorie.ts --outDir js --target ES2020`.
